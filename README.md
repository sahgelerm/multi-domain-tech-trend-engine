Разработка Data Science платформы мониторинга и выявления технологических трендов

Общая цель:
Создать production-ready прототип (MVP) аналитической системы, которая выполняет полный цикл сбора данных из открытых глобальных источников (OpenAlex, Google Patents), проводит их сопоставление, выявляет ранние сигналы технологического роста через анализ временных лагов и визуализирует тренды для поддержки стратегических решений R&D.

Система должна включать:
ETL-конвейеры для регулярной выгрузки данных из API и BigQuery,
Алгоритмы сопоставления научных топиков и патентных классификаторов (CPC/IPC),
Модуль расчета прогнозных метрик (Time Lag, CAGR, Trend Signal),
Интерактивный дашборд для фильтрации и визуализации данных,
Мониторинг качества данных и кэширование запросов.
